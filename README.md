# TERMINALSTUFF
Miscellaneous programs made for fun or for practical benefit in my local terminal

## deleteCache
I had an issue where my system data was taking up a crapton of space on my computer, and my fastest solution was a short script that essentially deletes the unwanted contents of any folder you specify. For me, it was the cache files of any site I hardly visit or that is hoarding info unnecessarily.

Initially it was just the simple script with my specific local filepath names hardcoded into a list, but I figured it would be cool to make it customizable so any computer can load the script on their terminal and add the specific filepath names they want scrubbed.

(This program specifically skips files that are meant to stay on your computer, so it's very low risk! Although I will say after scrubbing some of my Google cache folder, it sorta went haywire on me and began trying to fetch directly from the internet, so I suggest using this to delete mostly from things that you don't use too often.)
